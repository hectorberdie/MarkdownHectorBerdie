# Com preparar un bo i ràpid Ramen Instantani
> Una recepta senzilla i deliciosa per a un àpat ràpid

Preparar un ramen instantani és molt fàcil: bull l’aigua, afegeix els **fideus orientals** i els condiments del paquet. Finalment, incorpora un *topping*, com ara ou o verdures, per donar-li més sabor.

## Ingredients:
+ Paquet de ramen
+ Ou
+ Ceba tendra
+ Formatge fos

## Passos: 
- [x] Posar aigua a bullir.
- [ ] Coure els fideus exactament 3 minuts.
- [ ] Afegir l'ou i el formatge perquè es fonguin amb el brou.
